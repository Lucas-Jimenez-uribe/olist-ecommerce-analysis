# Análisis de E-commerce Olist

Análisis SQL + Python de 100K+ órdenes de un marketplace brasileño.

## Estructura
- `sql/`: Consultas SQL para análisis
- `notebooks/`: Análisis en Python
- `data/`: Datos originales y procesados
- `visualizations/`: Gráficas generadas
- `reports/`: Reportes finales

## Stack
- SQL: PostgreSQL
- Python: Pandas, Matplotlib, Seaborn
- Datos: 1.5M+ registros
